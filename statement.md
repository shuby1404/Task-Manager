# Project Statement

## Project Title

Task Manager

## Problem Statement

Managing multiple daily tasks manually can make it difficult to keep track of task priorities, scheduled times, completion status, and reminders.

The Task Manager project provides a simple command-line application that allows users to organize their daily tasks and monitor their progress.

## Project Scope

The project focuses on managing daily tasks through a Python command-line application.

The system allows users to:

* Add tasks.
* Enter task dates.
* Assign task priorities.
* Assign a suitable time of day.
* Set reminders.
* View pending tasks.
* Mark tasks as completed.
* Delete tasks.
* View task summaries and statistics.

## Target Users

The application is intended for users who want a simple way to organize and track their daily tasks using a command-line interface.

Examples include:

* Students
* Individual users
* People managing personal daily activities

## High-Level Features

1. Task creation
2. Date management
3. Priority management
4. Task time management
5. Reminder management
6. Task completion
7. Task deletion
8. Pending task display
9. Task summary
10. Task statistics

## Technology

The project is developed using Python and uses a modular structure with separate Python files for different functionalities.

## Expected Outcome

The expected outcome is a functional command-line Task Manager that allows users to organize daily tasks and track their status, priority, timing, and reminders.
